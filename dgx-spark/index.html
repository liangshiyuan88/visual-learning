The NVIDIA DGX Spark
How does a box the size of a hardback run a 200-billion-parameter AI model? Press the steps, or wait and the machine runs them by itself.×3

The big idea: the CPU and the GPU sit side by side in one chip package and share one pool of 128 GB, so a model of up to 200 billion parameters fits on a desk; two boxes linked run about 405 billion.
